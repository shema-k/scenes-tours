Connect to GitHub

How to create the token
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → scenes-tours.
  3. Repository permissions → Contents: Read and write. Metadata is added automatically.
  4. Set a short expiration, generate the token, and paste it above. Do not share it.

The token stays in this browser and is never written into the website files. Use a private device and a short-lived token. Anyone can open this page, but only a valid token can publish changes.
